Equipo

15. Equipo (EquipmentDef) → lista equipment

El objeto más rico en datos. Tiene display, una category, bloques tipados opcionales según el tipo, y grants para efectos mecánicos.

CampoTipoObligatorioNotas
idstringSí
displayDisplayInfoSí
categorystringSíWEAPON, ARMOR, SHIELD, TOOL, ADVENTURING_GEAR, CONTAINER, CONSUMABLE, FOCUS, WONDROUS, AMMUNITION…
subtypestring?NoSolo útil en algunas categorías. Arma: simple_melee/simple_ranged/martial_melee/martial_ranged. Armadura: light/medium/heavy. Herramienta: artisan/musical_instrument/game/other.
costCost?No{ "amount": 15, "unit": "gp" }.
weightdouble?NoEn kg.
raritystring?Nocommon, uncommon, rare, very_rare, legendary, artifact.
requiresAttunementboolNoDefault false.
bloques tipados—Noweapon, armor, shield, tool, container, focus, ammunition.
grants[Grant]NoEfectos mecánicos. Vacío = objeto descriptivo.

Bloques tipados más usados:

  • weapon (WeaponData): damageDice, damageType, versatileDice, properties, masteryProperty, attackAbilities, range { normal, long, unit }, fixedDamage.
  • armor (ArmorData): baseAc, category (LIGHT/MEDIUM/HEAVY), maxDex o dexterityCap, strengthRequirement, stealthDisadvantage.
  • shield (ShieldData): acBonus (default 2). Un escudo mágico se modela como escudo normal (bono base 2) más un grant AC_BONUS para el extra mágico, en vez de inflar acBonus.
  • tool, container, focus, ammunition: ver EquipmentDef.kt.

Paquetes de objetos (EXPAND_BUNDLE): un objeto que contiene otros (p. ej. "paquete de explorador") lleva un grant EXPAND_BUNDLE con contents (mapa id→cantidad). Al obtenerlo, el personaje recibe su contenido:

{
  "id": "explorers_pack",
  "display": { "name": "Paquete de explorador" },
  "category": "ADVENTURING_GEAR",
  "grants": [
    { "type": "EXPAND_BUNDLE", "contents": { "backpack": 1, "bedroll": 1, "rations": 10, "torch": 10 } }
  ]
}

Arma:

{
  "id": "longsword",
  "display": { "name": "Espada larga" },
  "category": "WEAPON",
  "subtype": "martial_melee",
  "cost": { "amount": 15, "unit": "gp" },
  "weight": 1.5,
  "weapon": {
    "damageDice": "1d8",
    "damageType": "slashing",
    "versatileDice": "1d10",
    "properties": ["versatile"],
    "masteryProperty": "sap",
    "attackAbilities": ["STR"]
  }
}

Objeto mágico con sintonización (los grants condicionados aplican al sintonizar/equipar):

{
  "id": "cloak_of_protection",
  "display": { "name": "Capa de protección" },
  "category": "ADVENTURING_GEAR",
  "rarity": "uncommon",
  "requiresAttunement": true,
  "grants": [
    { "type": "AC_BONUS", "amount": 1, "condition": "WHILE_ATTUNED" }
  ]
}

Ejemplo — Equipo — arma, armadura y objeto mágico

Arma marcial:

{
  "id": "ejemplo_espada",
  "display": { "name": "Espada rúnica" },
  "category": "WEAPON",
  "subtype": "martial_melee",
  "cost": { "amount": 15, "unit": "gp" },
  "weight": 1.5,
  "weapon": {
    "damageDice": "1d8",
    "damageType": "slashing",
    "versatileDice": "1d10",
    "properties": ["versatile"],
    "attackAbilities": ["STR"]
  }
}

Armadura media:

{
  "id": "ejemplo_coraza",
  "display": { "name": "Coraza élfica" },
  "category": "ARMOR",
  "subtype": "medium",
  "cost": { "amount": 400, "unit": "gp" },
  "weight": 9,
  "armor": { "baseAc": 14, "category": "MEDIUM", "addDex": true, "dexterityCap": 2 }
}

Escudo mágico (bono base 2 + extra mágico por grant, requiere sintonización):

{
  "id": "ejemplo_escudo_magnificencia",
  "display": { "name": "Escudo de la Magnificencia" },
  "category": "SHIELD",
  "rarity": "rare",
  "requiresAttunement": true,
  "shield": { "acBonus": 2 },
  "grants": [ { "type": "AC_BONUS", "amount": 3, "condition": "WHILE_ATTUNED" } ]
}
