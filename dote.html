Dote

12. Dote (FeatDef) → lista feats

Las dotes se referencian desde los CHOICE de kind: "FEAT" (en clases y trasfondos).

CampoTipoObligatorioNotas
idstringSí
categorystring?NoORIGIN, GENERAL, FIGHTING_STYLE, EPIC. Filtra qué CHOICE la ofrece.
displayDisplayInfoSí
prerequisitePrerequisite?NoRequisitos para poder elegirla.
repeatableboolNotrue = se puede tomar varias veces (p. ej. Mejora de característica). Default false.
mechanics[Grant]NoEfectos de la dote.

Prerequisite (todos los campos opcionales):

{
  "minLevel": 4,
  "ability": "STR",
  "abilityOptions": ["STR", "DEX"],
  "minScore": 13,
  "requiresSpellcasting": true
}

Usa ability + minScore para una característica única, o abilityOptions + minScore cuando basta con cumplir una de varias.

{
  "id": "tough",
  "category": "ORIGIN",
  "display": { "name": "Duro", "description": "Tus PG máximos aumentan en 2 por nivel.", "icon": "❤️" },
  "repeatable": false,
  "mechanics": [
    { "type": "MAX_HP_BONUS", "source": "PER_LEVEL", "perLevel": 2 }
  ]
}

La mayoría de las dotes del PHB 2024 combinan una mejora de característica (un CHOICE de kind: "ABILITY_SCORE_IMPROVEMENT") con uno o más grants de efecto. Patrones útiles:

  • Resiliente — mejora que además da competencia en la salvación de la característica elegida (grantsSavingThrowProficiency: true). Lleva repeatable: true porque puede tomarse para distintas características.
  • Lanzador ritual — mejora + un CHOICE de conjuros con ritual: true y pickFromStat: "PROFICIENCY_BONUS" (eliges tantos como tu bonif. de competencia).
  • Influencia feérica / sombría — mejora + INNATE_SPELL fijo + un CHOICE de conjuro filtrado por schools.
  • Moderadamente acorazado — mejora + PROFICIENCY (kind: "ARMOR"). Para topes numéricos (p. ej. el máximo de DES de armadura media) usa COMPUTED_STAT.
  • Dones épicos (category: "EPIC", prerequisite.minLevel: 19) — mejora hasta 30 + grants como SENSES (Don de la visión verdadera: truesightFeet) o un CHOICE de kind: "CUSTOM" cuyas options[].grants otorgan DAMAGE_RESISTANCE (Don de la resistencia a energías).
{
  "id": "resilient",
  "category": "GENERAL",
  "display": { "name": "Resiliente", "description": "+1 a una característica y competencia en sus salvaciones.", "icon": "🛡️" },
  "prerequisite": { "minLevel": 4 },
  "repeatable": true,
  "mechanics": [
    {
      "type": "CHOICE",
      "id": "resilient_boost",
      "title": "Mejora de Resiliente",
      "kind": "ABILITY_SCORE_IMPROVEMENT",
      "pool": ["STR", "DEX", "CON", "INT", "WIS", "CHA"],
      "points": 1,
      "grantsSavingThrowProficiency": true
    }
  ]
}
