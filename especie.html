Especie

11. Especie / raza (SpeciesDef) → lista species

CampoTipoObligatorioNotas
idstringSí
displayDisplayInfoSí
creatureTypestring?NoTipo de criatura (código en mayúsculas: HUMANOID, FEY, UNDEAD, CONSTRUCT, DRAGON, ELEMENTAL, …). null → la app asume HUMANOID.
speeddouble?NoVelocidad base en metros (p. ej. 9 = 9 m; goliat 10.5).
sizestring?NoTamaño por defecto (código: TINY, SMALL, MEDIUM, LARGE, HUGE, GARGANTUAN).
darkvisiondouble?NoRadio de visión en la oscuridad en metros (0 = no tiene).
traits[FeatureDef]NoRasgos raciales (mismo FeatureDef que las clases).
mechanics[Grant]NoGrants que aplican a nivel de especie.

Hay dos sitios para poner mecánicas: dentro de un trait (FeatureDef.mechanics) cuando forman parte de un rasgo con nombre propio, o directamente en mechanics de la especie para efectos globales. Preferir traits cuando el rasgo tiene su propio nombre y texto.

Tamaño a elección (CHOICE kind=SIZE)

Si la especie permite elegir tamaño (p. ej. el aasimar: Pequeño o Mediano), size guarda el tamaño por defecto y se añade un grant CHOICE de kind: "SIZE" en mechanics. El jugador elige al crear el personaje; sus opciones son exactamente las de la lista (no hay rango automático):

{
  "type": "CHOICE",
  "id": "aasimar_size",
  "title": "Tamaño de la especie",
  "kind": "SIZE",
  "level": 1,
  "options": [
    { "id": "SMALL",  "display": { "name": "Pequeño" } },
    { "id": "MEDIUM", "display": { "name": "Mediano" } }
  ]
}

Con un solo tamaño posible, omite el CHOICE y usa solo size.

{
  "id": "elf",
  "display": { "name": "Elfo", "flavorText": "…", "description": "…" },
  "speed": 9,
  "size": "MEDIUM",
  "darkvision": 18,
  "traits": [
    {
      "id": "elf_keen_senses",
      "display": { "name": "Sentidos agudos", "description": "Competencia en Percepción.", "icon": "👁️" },
      "mechanics": [ { "type": "PROFICIENCY", "kind": "SKILL", "items": ["Percepción"] } ]
    },
    {
      "id": "elf_fey_ancestry",
      "display": { "name": "Linaje feérico", "description": "Ventaja contra el estado hechizado." },
      "mechanics": [ { "type": "ADVANTAGE", "appliesTo": "SAVING_THROW", "condition": "VS_CHARMED" } ]
    },
    {
      "id": "elf_darkvision_trait",
      "display": { "name": "Visión en la oscuridad" },
      "mechanics": [ { "type": "SENSES", "darkvision": 18 } ]
    }
  ],
  "mechanics": []
}
El campo darkvision de la especie y un grant SENSES (darkvision) cumplen roles parecidos y ambos van en metros. El motor toma el máximo entre el darkvision de la especie y todos los SENSES activos (invocaciones, rasgos). Usa el campo para el dato base de la especie y el grant cuando el sentido lo aporta otra fuente. Ver §18 para unidades.

Ejemplo — Especie — con tamaño a elección y tipo de criatura

Especie con visión en la oscuridad, un rasgo con nombre y elección de tamaño Pequeño/Mediano.

{
  "id": "ejemplo_feerico",
  "display": { "name": "Trasgo feérico", "description": "Linaje menudo tocado por el Feywild." },
  "creatureType": "FEY",
  "speed": 9,
  "size": "SMALL",
  "darkvision": 18,
  "traits": [
    {
      "id": "ejemplo_feerico_suerte",
      "level": 1,
      "display": { "name": "Suerte feérica", "description": "Ventaja contra el estado hechizado." },
      "mechanics": [ { "type": "ADVANTAGE", "appliesTo": "SAVING_THROW", "condition": "VS_CHARMED" } ]
    }
  ],
  "mechanics": [
    {
      "type": "CHOICE",
      "id": "ejemplo_feerico_size",
      "title": "Tamaño de la especie",
      "kind": "SIZE",
      "level": 1,
      "options": [
        { "id": "SMALL",  "display": { "name": "Pequeño" } },
        { "id": "MEDIUM", "display": { "name": "Mediano" } }
      ]
    }
  ]
}
