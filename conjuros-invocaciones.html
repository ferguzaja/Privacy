Conjuros e invocaciones

13. Conjuro (SpellDef) → lista spells

Los conjuros no usan grants: son datos estáticos. Se enlazan con clases por classes / spellListClassId.

CampoTipoObligatorioNotas
idstringSí
displayDisplayInfoSí
levelintSí0 = truco (cantrip).
schoolstring?NoEscuela (texto libre).
castingTimestring?NoP. ej. "1 acción".
rangestring?No
componentsstring?NoP. ej. "V, S, M".
durationstring?No
concentrationboolNoDefault false.
ritualboolNoDefault false.
higherLevelstring?NoEfecto a niveles superiores.
classes[string]NoIDs de clases con acceso. Cruza con SPELLCASTING.spellListClassId.
damageSpellDamage?NoDaño estructurado: la tarjeta del conjuro ofrece una celda para tirarlo. Ver abajo.
healingSpellHealing?NoCuración estructurada (celda verde de tirada). Ver abajo.
activeEffectSpellActiveEffect?NoEfecto que el conjuro mantiene mientras está activo (interruptor «Activar»). Ver abajo.

Códigos de escuela. school es texto libre, pero el catálogo y los filtros (schools en un CHOICE, SPELL_DAMAGE_BONUS) usan: ABJURACION, ADIVINACION, CONJURACION, ENCANTAMIENTO, EVOCACION, ILUSION, NIGROMANCIA, TRANSMUTACION.

damage (SpellDamage) — todos los campos salvo dice y type son opcionales:

CampoNotas
diceDados al nivel más bajo: "8d6" (Bola de fuego) o "1d10" (truco a nivel 1).
typeTipo de daño (fire, radiant…; mismos 13 tipos de §5.2).
scaling{ "rule": "CANTRIP_LEVEL" \| "SLOT_LEVEL", "dicePerStep": "1d6" }. CANTRIP_LEVEL añade esos dados a nivel de personaje 5, 11 y 17; SLOT_LEVEL, por cada nivel de espacio sobre el base. Sin scaling el daño es fijo.
saveCaracterística de la salvación del objetivo ("DEX"). Ausente = ataque de conjuro (la ficha muestra la tirada de ataque).
halfOnSavetrue = salvar reduce el daño a la mitad.
countPara conjuros que escalan en cantidad de tiradas y no en dados: { "rule": "FIXED" \| "CANTRIP_LEVEL" \| "SLOT_LEVEL", "base": 3, "perStep": 1, "label": "dardos" } (Proyectil mágico, Rayo abrasador). La ficha muestra «×N dardos»; cada tirada la haces tú.

healing (SpellHealing): dice (dados base), scaling (igual que en el daño) y addSpellMod (default true: suma el modificador de aptitud mágica).

Gasto del espacio. La ficha tira los dados, pero no gasta el espacio de conjuro por ti: el jugador lo marca a mano. El selector de nivel de lanzamiento sí ofrece los niveles de espacio que tienes (los de pacto del Brujo incluidos) para calcular el escalado.

activeEffect (SpellActiveEffect) — conjuros que se encienden y se apagan mientras duran:

CampoPara qué
weaponBonusDamageLista de { "dice", "type" } que se suma a cada ataque con arma mientras está activo (Favor divino 1d4 radiante, Maleficio 1d6 necrótico, Marca del cazador).
attack / attacksAtaque(s) que el conjuro crea: { "damage": SpellDamage, "addSpellMod": true, "name": "Puño cerrado" }. Añaden una fila en Combate (Arma espiritual, Mano de Bigby). Si el damage lleva save, la fila muestra la CD en vez del d20.
weaponAbilityTus ataques con arma usan tu aptitud mágica (Impacto certero, Shillelagh): weaponIds, meleeOnly, damageDiceByTier (dado del arma en [nv.1, nv.5, nv.11, nv.17]), grantsProficiency.

Encender un conjuro de concentración apaga el anterior; un descanso apaga todos. No hay temporizador: el jugador lo apaga cuando termina.

{
  "id": "fire_bolt",
  "display": { "name": "Rayo de fuego", "description": "Lanzas una mota de fuego…" },
  "level": 0,
  "school": "Evocación",
  "castingTime": "1 acción",
  "range": "36 m",
  "components": "V, S",
  "duration": "Instantánea",
  "higherLevel": "El daño aumenta a niveles 5, 11 y 17.",
  "classes": ["sorcerer", "wizard"],
  "damage": { "dice": "1d10", "type": "fire", "scaling": { "rule": "CANTRIP_LEVEL", "dicePerStep": "1d10" } }
}

Conjuro de área con salvación y escalado por nivel de espacio:

{
  "id": "fireball",
  "display": { "name": "Bola de fuego" },
  "level": 3,
  "school": "EVOCACION",
  "classes": ["sorcerer", "wizard"],
  "damage": {
    "dice": "8d6", "type": "fire", "save": "DEX", "halfOnSave": true,
    "scaling": { "rule": "SLOT_LEVEL", "dicePerStep": "1d6" }
  }
}

Conjuro con varias tiradas (escala en cantidad), y después uno que se activa:

{
  "id": "magic_missile",
  "display": { "name": "Proyectil mágico" },
  "level": 1, "school": "EVOCACION", "classes": ["sorcerer", "wizard"],
  "damage": { "dice": "1d4+1", "type": "force",
              "count": { "rule": "SLOT_LEVEL", "base": 3, "perStep": 1, "label": "dardos" } }
}
{
  "id": "divine_favor",
  "display": { "name": "Favor divino" },
  "level": 1, "school": "EVOCACION", "concentration": true, "classes": ["paladin"],
  "activeEffect": { "weaponBonusDamage": [ { "dice": "1d4", "type": "radiant" } ] }
}

14. Invocación sobrenatural (InvocationDef) → lista invocations

Invocaciones del Brujo (u otras clases que declaren invocaciones con el grant INVOCATIONS). Cada invocación es presentación + prerequisitos + mecánicas.

CampoTipoObligatorioNotas
idstringSí
displayDisplayInfoSí
minLevelintNoNivel mínimo de clase. Default 1.
prerequisiteIds[string]NoIDs de otras invocaciones requeridas.
pactRequiredstring?NoPacto necesario (p. ej. "PACT_OF_THE_BLADE").
mechanics[Grant]NoSuele ser INNATE_SPELL, AC_FORMULA o PROFICIENCY.
{
  "id": "agonizing_blast",
  "display": { "name": "Explosión agonizante", "description": "Sumas tu mod. de Carisma al daño de Descarga sobrenatural." },
  "minLevel": 1,
  "prerequisiteIds": [],
  "mechanics": [
    { "type": "DAMAGE_BONUS", "source": "ABILITY_MOD", "ability": "CHA", "attackTypes": ["eldritch_blast"] }
  ]
}
