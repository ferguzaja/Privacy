Trasfondo

10. Trasfondo (BackgroundDef) → lista backgrounds

Un trasfondo es simple: presentación + mecánicas + equipo inicial.

CampoTipoObligatorioNotas
idstringSíIdentificador único.
displayDisplayInfoSí
mechanics[Grant]NoCompetencias, dotes de origen, conjuros, etc.
startingEquipment[EquipmentItem]NoCada ítem: { "display": { "name": "…" }, "id": "…" }. El id (opcional) enlaza al catálogo; ver §2.1.
goldAlternativeint?NoOro alternativo al equipo.

En el PHB 2024 el trasfondo suele otorgar competencias, una dote de origen y una mejora de característica. Todo eso se modela con grants:

{
  "id": "sage",
  "display": { "name": "Sabio", "description": "Pasaste años estudiando…", "icon": "📚" },
  "mechanics": [
    { "type": "PROFICIENCY", "kind": "SKILL", "items": ["Arcanos", "Historia"] },
    { "type": "PROFICIENCY", "kind": "TOOL", "items": ["Utensilios de calígrafo"] },
    {
      "type": "CHOICE",
      "id": "sage_asi",
      "title": "Mejora de característica del trasfondo",
      "pick": 1,
      "kind": "CUSTOM",
      "options": [
        { "id": "sage_int2", "display": { "name": "+2 INT" }, "grants": [ { "type": "ABILITY_BOOST", "boosts": [ { "ability": "INT", "amount": 2, "max": 20 } ] } ] }
      ]
    },
    {
      "type": "CHOICE",
      "id": "sage_origin_feat",
      "title": "Dote de origen",
      "pick": 1,
      "kind": "FEAT",
      "category": "ORIGIN"
    }
  ],
  "startingEquipment": [
    { "display": { "name": "Libro de saberes" } },
    { "display": { "name": "8 po" } }
  ],
  "goldAlternative": 50
}
